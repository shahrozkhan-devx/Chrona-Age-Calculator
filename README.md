# 🎂 Age Calculator App

A simple and beginner-friendly Age Calculator web application built using HTML, CSS, and JavaScript.

This project calculates the user's age based on their selected birth date and displays the result instantly.

---

## 🌐 Live Demo

👉 **View Project Here:**  
https://danish-devx.github.io/Age-Generator-App/

---

## 🚀 Features

- 📅 Select birth date using date input  
- 🧮 Calculate age in years  
- ⚠️ Input validation with Toastr notification  
- 🔄 Reset button to clear input and result  
- 🎨 Clean and modern UI design  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- Toastr.js (for notifications)
